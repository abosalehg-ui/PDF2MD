# pdf2md

أداة سطح مكتب لاستخراج **نص عربي سليم** من ملفات PDF المعطوبة، وتحويله إلى **Markdown منظَّم**.

---

## المشكلة التي تحلّها

ملفات PDF العربية المصدَّرة من Word ثم المعالَجة عبر macOS/iOS (محرّك Quartz) — وهي شائعة جدًّا في الكتب والأنظمة والوثائق العربية — تحمل خللًا في خريطة `ToUnicode`: **الرباطات العربية تُخزَّن بترتيب معكوس**.

النتيجة عند النسخ أو التحويل بأي أداة عادية:

| الصحيح | ما يخرج فعليًّا |
|---|---|
| المادة | املادة |
| اللائحة | الالئحة |
| المملكة | اململكة |
| الأول | األول |
| وتاريخ | واتريخ |
| اللازم | الالزم |

`pdftotext`، `PyMuPDF`، `Marker`، ومحوّلات الويب كلها تنتج هذا التلف، لأن المشكلة في الملف نفسه لا في الأداة. في كتاب واحد قد تتجاوز الكلمات التالفة **اثني عشر ألف كلمة**.

---

## كيف تعمل

الأداة **لا تخمّن ولا تعتمد على قاموس**. كل الإصلاحات مبنية على قواعد هندسية مأخوذة من إحداثيات الحروف على الصفحة.

### ١. إصلاح الرباطات المقلوبة
الحرف الثاني في الرباط يُصدَّر بعرض **صفر** لأنه ملتصق بجليف واحد. فأي حرف عرضه صفر (وليس تشكيلًا) = جزء رباط ⟵ يُبدَّل مع الحرف الذي يليه.

يغطي: `لا` `لأ` `لإ` `لآ` `لم` `لح` `لج` `لخ` `تا` `با` `في` وغيرها — يُكتشف النوع تلقائيًّا.

### ٢. إعادة بناء السطر البصري
`PyMuPDF` يقسّم السطر الواحد عند كل تغيّر اتجاه، فينتج:

```
المادة الثانية
والعشرون(
22
):(
1)
```

الأداة تجمع كل الأجزاء الواقعة على المستوى الرأسي نفسه، وترتّبها من اليمين لليسار، لتعيد بناء `المادة الثانية والعشرون(22):(1)`.

**حماية من التداخل:** لا يُدمج جزآن يتداخلان أفقيًّا — هذا يمنع تعجّن حروف الجداول متعددة الأعمدة.

### ٣. فحص الحبر — كشف المسافات الوهمية
بعض ملفات PDF تحتوي على حروف مسافة **لا تُرسم فعليًّا** لأن الحرف مرسوم فوقها. فتخرج `يقتض ي` و`الأ صلي` و`المرسو م` والكلمة في الأصل متصلة.

الأداة ترسم الصفحة وتقيس كثافة الحبر داخل كل مسافة مرشّحة:

- مسافة حقيقية: **≤ ٢٪** حبر
- مسافة وهمية: **٩–٢١٪** حبر

الفصل قاطع، والهامش واسع. (هذا الخيار يُبطئ المعالجة نحو ٣×، ويمكن تعطيله.)

### ٤. ترتيب الأرقام والتواريخ
الأرقام تُكتب من اليسار لليمين داخل نص عربي، فتخرج معكوسة. الأداة تكتشف التسلسلات الرقمية وتعيدها لترتيبها المنطقي، وتتعامل مع الأرقام الهندية `٠١٢٣` والعربية `0123` **مختلطة في العدد نفسه**، وتصلح المسافات الدخيلة التي تكسر التاريخ (`6/5/1436` ⟵ `1436/6/5`).

### ٥. التشكيل الطائر
علامات التشكيل تُصدَّر منفصلة وقد تلتصق بالحرف الخطأ (`يوما.ً`). الأداة تربط كل علامة بالحرف العربي الذي يحتويها إحداثيًّا (`يوماً.`).

### ٦. البنية
- **العناوين** — بحجم الخط، أو بأنماط `الباب / الفصل / المادة` في نمط الأنظمة السعودية
- **الفقرات** — تُلَمّ الأسطر المكسورة في فقرة واحدة بالاعتماد على الفجوات الرأسية
- **البنود المرقّمة** — `1-` و`3/1-` تُحفظ بترقيمها الأصلي دون إعادة ترقيم
- **الحواشي** — تُلتقط بحجم الخط الأصغر وتُؤجَّل حتى نهاية القسم لئلا تقطع الفقرات
- **الترويسة والتذييل** — تُرصد بتكرارها عبر الصفحات وتُحذف
- **الفهرس الأصلي** — يُتخطّى، ويُولَّد بدلًا منه فهرس بروابط داخلية

## التثبيت

```bash
pip install -r requirements.txt
```

المتطلبات: `PyQt6` و`PyMuPDF` و`numpy` — وبايثون ٣٫٩ فأحدث.

## التشغيل

| الطريقة | الأمر |
|---|---|
| الواجهة الرسومية | `python -m arpdf2md` |
| ويندوز | نقرًا مزدوجًا على `run.bat` |
| لينكس/ماك | `./run.sh` |
| سطر الأوامر | `python -m arpdf2md.cli ملف.pdf -o مخرج.md` |

### أمثلة سطر الأوامر

```bash
# فحص تشخيصي قبل التحويل
python -m arpdf2md.cli كتاب.pdf --diag

# نظام سعودي بعناوين الباب/الفصل/المادة
python -m arpdf2md.cli نظام.pdf --profile saudi_law --title "نظام العمل" -o نظام.md

# نطاق صفحات + وضع سريع بلا فحص حبر
python -m arpdf2md.cli كتاب.pdf --pages 20-60 --no-ink

# دفعة كاملة إلى مجلد
python -m arpdf2md.cli *.pdf -o ./md/
```

## الواجهة

| العنصر | الوظيفة |
|---|---|
| **قائمة الملفات** | إضافة بالسحب والإفلات أو بالزر — تدعم التحويل الدُفعي |
| **نمط المستند** | `تلقائي` بحجم الخط، `نظام سعودي` بالأنماط، `نص عادي` بلا عناوين |
| **مستوى العناوين** | تحديد `##` و`###` أو أي مستوى آخر |
| **نطاق الصفحات** | للتجربة على جزء قبل تحويل الملف كاملًا |
| **الحواشي** | اقتباس منفصل `>` أو ضمن النص أو حذف |
| **زر الفحص التشخيصي** | جدول قبل/بعد لثماني كلمات مؤشّرة + عيّنة من النص |
| **تبويب المعاينة** | الناتج مباشرة قبل الحفظ |
| **تبويب السجل** | تفاصيل التنفيذ وأي أخطاء |

التحويل يعمل في خيط منفصل، فالواجهة لا تتجمّد.

---

## الحدود المعروفة

- **الملفات المصوّرة** (بلا طبقة نص) خارج نطاق الأداة — تحتاج OCR أولًا. الفحص التشخيصي يخبرك بذلك.
- **الجداول متعددة الأعمدة** تخرج كل خلية في سطر مستقل — مقروءة، لكنها ليست جدول Markdown.
- **الأخطاء المطبعية في الأصل** تُنقل كما هي — الأداة أمينة للمصدر ولا تصحّح المحتوى.
- الأداة موجَّهة للعربي، لكنها تكتشف الأسطر اللاتينية تلقائيًّا وتعاملها من اليسار لليمين.

## البنية

```
arpdf2md/
├── core.py         محرّك الاستخراج — الرباطات، الاتجاه، الحبر، المسافات
├── structure.py    طبقة البنية — العناوين، الفقرات، الحواشي، الأنماط
├── gui.py          واجهة PyQt6
├── cli.py          سطر الأوامر
└── __main__.py     نقطة الدخول
```

`core.py` مستقل تمامًا ويمكن استعماله وحده:

```python
import fitz
from arpdf2md import core

doc = fitz.open("ملف.pdf")
for line in core.page_lines(doc[0]):
    print(line["text"], line["size"], line["bold"])
```

أو الحزمة كاملة:

```python
from arpdf2md import Options, convert, diagnose

md, stats = convert("ملف.pdf", Options(profile="saudi_law", title="عنوان"))
report = diagnose("ملف.pdf")
```

### ثوابت المعايرة في `core.py`

| الثابت | القيمة | المعنى |
|---|---|---|
| `ZERO_W` | 0.05 | عرض يُعتبر صفرًا (كشف الرباط) |
| `GAP_RATIO` | 0.13 | فجوة ÷ حجم الخط تُعدّ مسافة |
| `INK_MAX` | 0.06 | كثافة حبر تكشف المسافة الوهمية |
| `INK_BAND` | 0.78 | نتجاهل الربع السفلي (الذيول والتسطير) |
| `CELL_GAP` | 6.0 | فجوة أفقية تفصل خلايا الجدول |
| `Y_TOL` | 0.55 | تسامح رأسي لتجميع السطر |

عدِّلها إن واجهت ملفًا بخصائص مختلفة.
